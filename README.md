# Shapelab — Free Offline Installer

![Category](https://img.shields.io/badge/VR_Sculpting-blue?style=flat-square)

## About

Shapelab is a 3D sculpting application for VR headsets that enables artists to sculpt in a truly spatial, immersive environment using hand controllers. With tools like clay buildup, smoothing, and boolean operations, Shapelab leverages VR interaction to make 3D sculpting feel as natural as working with physical clay. Export finished sculpts to industry-standard formats.

## Common Problems & Limitations

- **VR Headset Required** — Only works with compatible VR hardware
- **VR Space Required** — Comfortable use requires adequate physical play space
- **Precision Limitation** — VR controller precision less fine than mouse for detailed work
- **Battery/Tethering** — VR session length limited by headset power
